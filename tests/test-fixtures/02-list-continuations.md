# 列表续行边界情况

## 简单续行

- 这是一个带有续行的列表项
  该续行换行到下一行
- 这是一个普通的单行项

## 多行续行

- 此项有多个
  续行，它们
  都应合并为一个项目符号
- 下一项

## 带续行的嵌套列表

- 顶层项
  - 带有长描述的嵌套项
    该描述在下一行继续
  - 另一个嵌套项
- 回到顶层

## 带续行的深层嵌套

- 第 0 层
  - 第 1 层带续行
    在此处换行
    - 第 2 层项
      - 第 3 层带续行
        同样换行

## 空行后的续行（不应合并）

- 第一项

  这应是一个独立段落，不应合并到列表项中。

- 第二项

## 列表后的非缩进行（不应合并）

- 项一
这没有缩进，因此应是一个新段落。
- 项二

## 列表项后的混合内容

- 项后跟标题
# 此标题不应合并

- 项后跟块引用
> 此引用不应合并

- 项后跟代码围栏
  ```ts
  const x = 1;
  ```

- 项后跟表格
| A | B |
|---|---|
| 1 | 2 |

- 项后跟水平分隔线
