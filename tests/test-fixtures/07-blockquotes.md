# 块引用渲染测试

## 多行块引用（该 bug）

这是一个多行块引用。修复前，每个 `>` 行都渲染成独立的块引用框，各自带上下外边距，导致每行之间出现可见间隙。修复后，所有连续的 `>` 行应合并为一个连续的引用块。

> `tree.hash(path)` 返回该文件的 SHA-256 摘要，取值基于库最后一次观察到的文件状态。首次调用时，根据当时的磁盘字节计算摘要，缓存到 `files.hash`，后续调用直接返回。只要库**观察到**该行发生变化（watcher 或 reconcile 更新），缓存即失效；该行被删除时缓存丢弃。库通过 watcher 流水线和 reconcile 过程观察变化，二者都按规范 §"Event flow and normalization" 跟踪 `(size, mtime)`。若内容变化但 `(size, mtime)` 未变——例如保持 mtime 的等长原子覆盖，或被 watcher 丢弃的基于间隔的编辑——库无法察觉，缓存哈希**不会**失效。
