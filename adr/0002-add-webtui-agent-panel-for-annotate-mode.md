# 2. 为标注模式添加 WebTUI 智能体面板

日期：2026-06-16

## 状态

已接受

## 背景

Plannotator 标注模式支持在 plan 应用中审阅单个文件或文件夹中的文件。用户有时需要在标注这些文件的同时运行编码智能体。

WebTUI 提供可导入的 React 终端、xterm.js 渲染、基于 node-pty 的真实 PTY、内置智能体启动方案、PTY 退出事件以及 PTY 终止支持。

该功能应保持标注模式轻量。打开标注会话时，在用户明确启动智能体之前，不得启动智能体进程或分配 PTY。

## 决策

我们将仅在 `plannotator annotate` 中添加可选的、由 WebTUI 驱动的智能体终端。

这适用于单文件和文件夹标注，不适用于 plan 审阅、代码审阅、归档、目标设置或 `annotate-last`。

面板从左上角、现有侧边栏控件旁的图标打开。该图标复用代码审阅智能体任务所用的现有 `ReviewAgentsIcon`。

打开后，布局为：

```text
[ 智能体终端面板 ] [ 文件/目录侧边栏 ] [ 文档 ] [ 标注/AI 面板 ]
```

智能体终端面板与文件侧边栏相互独立，可调整大小、可折叠。

不会自动启动任何智能体。首次打开时显示一个小的启动视图。用户选择智能体并启动。用户可将该选择保存为后续标注会话的默认值。

终端在 Plannotator 原始启动目录中启动一个选定的 WebTUI 内置智能体。除非该目录同时也是启动目录，否则不会从被标注的文件或文件夹路径启动。

第一版不提供任意命令输入框、自动提示注入、标注同步、文件侧边栏集成、多智能体或后台智能体任务。

停止或关闭时，Plannotator 会清理终端进程。UI 应先视情况发送中断输入，若智能体未退出，再终止 PTY。若进程自行退出，WebTUI 的 `onExit` 会将面板标记为已停止或将其关闭。

标注服务器会向浏览器暴露启动 cwd，并提供面板所需的 WebTUI PTY 后端/WebSocket 支持。终端 WebSocket 使用与标注服务器相同的浏览器侧源和端口。

Bun 标注服务器将使用 Bun 的 WebSocket 运行时实现浏览器侧 WebSocket 路由，并将其代理到按需启动的 Node sidecar，该 sidecar 运行 WebTUI 的 Node PTY WebSocket 服务器。sidecar 绑定回环地址上的随机内部端口，仅在用户启动终端时启动，且不暴露给浏览器。这样既保持了浏览器同源行为，又使用了 WebTUI 示例所用的 Node 运行时路径。

Pi Node 标注服务器会将 WebTUI 的 Node WebSocket 服务器挂载到现有 Node HTTP 服务器上。两种运行时都应暴露相同的浏览器侧路径和能力形态。

服务器关闭时必须清理所有活动 PTY 会话。在 Bun 运行时中，当 Bun 父进程退出或关闭其父进程死亡管道时，sidecar 也必须退出。

如果包含 Pi 标注支持，Pi Node 标注服务器必须镜像 Bun 标注服务器的支持。

## 影响

在用户启动智能体之前，标注会话保持轻量。

用户可以在标注的同时，在同一工作区中查看文件并运行智能体。

该功能为 Plannotator 增加了 WebTUI 依赖。发布前，WebTUI 必须通过发布、vendoring 或其他明确的包策略作为真实依赖提供。

该功能依赖 node-pty。如果 WebTUI 或 node-pty 无法在用户机器上加载，标注模式必须继续可用，并应禁用智能体终端并给出明确提示。

服务器为标注会话承担 PTY/WebSocket 生命周期责任。

使用现有 Plannotator 浏览器侧端口，可避免远程、SSH 和 devcontainer 会话中的额外端口转发摩擦。

Bun 运行时多了一个活动部件：终端启动后的 Node sidecar 进程。这是有意为之。本地验证显示，WebTUI 的 `NodePtyBackend` 在 Bun 下可以启动 PTY，但不传输任何终端数据；而同一后端在 Node 下能正确传输 shell 和 Claude 输出。sidecar 将风险运行时边界保持得较小，并隔离在终端传输层。

第一版有意保持范围狭窄。与审阅模式、plan 模式、annotate-last、标注上下文或智能体任务的更广泛集成可留待以后考虑。
