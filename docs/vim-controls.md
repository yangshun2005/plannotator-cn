# Vim 控制

Vim 控制为 plan 和 annotate 应用提供可选的、完全由键盘驱动的 Select 和 Pinpoint 标注。

## 目标

- 添加可选的 Vim 模式设置，默认关闭。
- 提供第二个独立可选的 HUD，仅可视化已处理的 Vim 命令。
- Vim 模式关闭时，保留所有现有的指针和键盘交互。
- 在 Select 和 Pinpoint 中均支持键盘导航和标注。
- 支持 Markdown 和原始 HTML 文档。
- 键盘创建的标注与指针创建的标注走同一标注流水线。
- 以渲染文档的语义结构（而非 DOM 焦点）作为主要导航模型。
- 指针 Pinpoint 和键盘导航共用同一语义目标图。
- 用自动化测试针对代表性文档覆盖该行为。

## 兼容性不变量

1. 除非用户显式启用，否则所有现有用户的 Vim 模式均处于禁用状态。
2. Vim 模式禁用时，任何 Vim 按键处理器不得消费或改变未修饰的按键。
3. 当焦点位于输入框、textarea、contenteditable 区域、对话框、标注编辑器、标签选择器、图片编辑器或其他嵌入式编辑器时，Vim 命令永不执行。
4. `Tab` 和 `Shift+Tab` 保持原生焦点导航行为。
5. 指针 Select、指针 Pinpoint、按住 Alt 和双击 Alt 继续按现有方式工作。
6. 键盘选择必须创建与对应指针选择相同的标注数据和高亮 DOM。
7. Escape 仅回退最内层的活动 Vim/标注状态。

## 预期交互

### 导航模型

`DOCUMENT → BLOCK → INLINE TARGET → TEXT → VISUAL SELECTION`

- 激活 Vim 控制后，进入距视口最近的语义块（**BLOCK**）：段落、标题、列表项、代码块、表格等。
- 页面处于中性状态时，启用的文档自动获得键盘焦点。从应用外壳按 `Escape` 将焦点返回文档；编辑器和打开的对话框优先拥有该按键。
- `j` / `k`：下一个或上一个块；细化后，下一个或上一个语义同级（例如另一表格行、单元格或内联目标）。
- `gg` / `G`：第一个或最后一个块。
- `l`：细化进入子目标；从最深层目标进入文本。
- `h`：返回包含它的目标。
- `v`：开始或结束字符级 Visual 选择。
- `V`：选中整个当前块；`j` / `k` 按整块扩展。
- 文本中，`h` / `l`、`w` / `b` / `e`、`0` / `$`、`j` / `k` 使用精确光标移动。
- `o`：交换选择区的固定端和移动端。
- `Escape`：精确回退一级。

文档元素可拥有技术性键盘焦点，但绝不绘制为活动目标。未启用可选 HUD 时，BLOCK 和 INLINE 使用现有 Pinpoint 底色，TEXT 使用光标，VISUAL / VISUAL BLOCK 使用浏览器选择。紧凑状态徽章显示 BLOCK、INLINE、NORMAL、VISUAL、VISUAL BLOCK 或 ACTION。额外启用 **Vim HUD** 的用户会在真实文档上获得视频式效果：活动语义块、光标或选择区周围出现紫色四角准星和目标标签，右下角还有更大的命令显示，包含最近处理的按键、活动导航粒度、输入法和上下文操作说明。HUD 中可见的 **Key map** 控件（或 `?`）将同一右下角面板展开为完整图例，按 Document、Text、Select、Annotate 和 Control 命令分组。与当前导航层级匹配的分组会高亮，让学习者分辨 `j` / `k` 是按块还是按行移动。原始 HTML 在其沙箱 iframe 内镜像相同的目标处理，同时使用共享的父级按键 HUD 和键位图。

右下角 **Key panel** 独立持久化，为向后兼容默认开启。其 Hide 控件仅移除该面板；准星、光标和 Vim 导航保持活动。用户可在 **Settings → Vim** 中恢复，或在隐藏时按 `?` 临时打开完整键位图。关闭键位图后返回仅准星的 HUD。

指针 Pinpoint 和键盘导航通过同一规范图解析，该图拥有目标标识、层级、标签、标注范围和覆盖元素。表格行、单元格和内联格式仍可键盘到达：`l` 进入层级，`j` / `k` 在同级间移动，`h` 返回父级后恢复块导航。

### 操作

- `Enter`：使用活动的 Markup、Comment、Redline 或 Label 模式。
- `Space`：打开现有标注操作工具栏。
- `c`：评论。
- `d`：红线/删除。
- `m`：标记。
- `t`：标签。
- `y`：复制。
- `Escape`：取消一层。
- `?`：展开或折叠上下文 HUD 键位图。

标注操作作用于 BLOCK/INLINE 目标或活动 VISUAL 范围。在 NORMAL 文本状态下，先用 `v` 创建范围；折叠的光标不会被静默提升为整个包含块。

## 架构

Markdown 文档使用指针 Pinpoint 和键盘导航共享的规范语义目标图。该图拥有块顺序、层级、标签、标注范围和覆盖元素。文本位置序列化为块 ID 加文本偏移，因此光标和 Visual 状态在高亮 DOM 变更后仍能保留，不会持有过期的文本节点。

键盘创建的范围进入与指针选择相同的 `@plannotator/web-highlighter` `fromRange()` 流水线。代码块和公式保留其专用标注路径。原始 HTML 将范围和焦点状态保留在沙箱 iframe 内，然后通过现有、经来源验证的标注桥接发送。

Vim 控制通过 cookie 持久化，默认关闭，作用域为聚焦的文档。不安装全局字母键监听器。禁用该设置会移除文档焦点表面，现有行为保持不变。Vim HUD 独立通过 cookie 持久化，默认关闭，仅在启用时记录或渲染命令。输入到标注编辑器中的文本既不被捕获也不显示。HUD 按键面板独立通过 cookie 持久化，默认开启，且从不控制准星。

两个控件均位于各自的 **Settings → Vim** 面板中。Shortcuts 面板保留用于键位绑定参考。
